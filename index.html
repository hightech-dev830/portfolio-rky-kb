About me

Turning large language models into trustworthy business tools

I'm a senior engineer who works across the whole stack, from Postgres schemas and Go services to React interfaces. For the last several years I've focused on bringing LLMs into real business workflows: AI agents, retrieval-augmented generation, document intelligence, semantic search and structured data extraction.

I've built these systems for law firms, government contractors and financial platforms, where a wrong answer or a leaked record has real consequences. So I care a lot about the unglamorous parts: secure data access, tenant isolation, validation, observability and architecture that the next engineer can actually maintain.

🛡️

Secure by design

Permission-aware retrieval, RBAC, scoped API keys and PII scrubbing are built in from the start, not added later.

✅

Validated outputs

LLM output goes through Pydantic schemas, guardrails and tests before anything downstream relies on it.

🔭

Observable systems

Monitoring, background-job visibility and clear error handling so production issues get found and fixed fast.
